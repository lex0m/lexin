# 乐信（lexin）

微信的 Xposed / LSPosed 模块。纯 Java，无 Gradle。协议 MIT。

- 包名 `io.github.lex0m.lexin`
- 版本 **v1.1**（versionCode 3）
- 下载：[Releases](../../releases) · 编译产物 `dist/lexin.apk`

## 三个主力功能

**防撤回**：对方撤回的消息原样留着（抹掉微信那条撤回指令，不发请求）。撤回的气泡压暗，正下方贴个小标签写「对方撤回」——不压住原消息、切后台回来也不跑位。自己撤回不贴标签。

**运动步数**：三种模式分开——**直接指定**（填 12000 就是 12000，立刻生效）、**自动增加**（每小时 +N 步）、**倍率**（按真实步数放大）。带额外步数上限（默认 20000）。走外部通道：优先改微信自己算出的「今天步数」（各家手机步数来源不同，微信内部已适配，换品牌不用改），挂不上退回传感器层，一条代码都不碰微信。

**去广告**：朋友圈信息流（掐广告对象构造）、小程序开屏、开屏广告判定。只拦本地，不改网络请求。三处同一个开关。

## 其它

朋友圈保留 · 解除扫码限制（相册/长按图片按相机处理）· 自动查看原图 · 放宽本地限制 · 骰子猜拳自选 · 界面美化（全屏背景/卡片化/聊天条/毛玻璃）· 面板顶部每日一言 + 当前登录微信头像昵称 · 首次打开两秒免责声明（含禁止国内传播）

## 装

装 `dist/lexin.apk` → LSPosed 勾选「乐信」并作用域勾微信 → 强行停止微信再打开。

打开面板：① LSPosed 模块页右下角 ▶ ② 桌面「乐信」图标 ③ 微信里 我 → 设置 → 更多 → 关怀模式 → **长按「开启」**

## 支持版本

| 微信 | 适配 |
| --- | --- |
| 8.0.79 / 8.0.78 / 8.0.77 / 8.0.76 / 8.0.74 / 8.0.72 | 已内置实测表，8.0.78 实测 9/9 |
| 其它版本 | 自己扫 dex 适配（类名 + 方法内字符串 + 方法签名三层特征），找不到的功能安静跳过 |

新版本补表：`python3 tools/gen-anchors.py . 8.0.80=/path/apk` 然后 `sh build.sh`。

## 构建

```sh
PREFIX=<jdk/aapt2/apksigner 前缀> sh build.sh   # 产物 dist/lexin.apk
```
